## 💡 How to Choose

| Goal | Recommendation |
|------|----------------|
| **Just starting, zero budget** | Free official training (MS Learn, AWS Skill Builder, Skills Boost) + freeCodeCamp YouTube |
| **Want a resume credential** | Foundational cert first (AZ-900 / AWS Cloud Practitioner / GCP Digital Leader) |
| **Hands-on DevOps job** | CKA + Terraform Associate + a cloud Associate cert |
| **Free but structured** | edX/Coursera **audit mode** (learn free, skip the paid cert) |
| **Budget for one cert** | Pick the cloud your target employer uses; do the Associate level |

> 🎟️ **Money-saving tips:** Microsoft **Virtual Training Days** give free exam vouchers; Udemy courses go on sale often ($10–15); use **free-tier cloud accounts** for hands-on practice; audit Coursera/edX for free.
