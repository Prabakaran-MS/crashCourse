# ✅ Self-Check Quiz & Answers

A quick **50-question** quiz to test your knowledge. Answers are at the bottom — no peeking! Score yourself.

---

## 📝 Multiple Choice

**1.** Which is NOT a cloud service model?
A) IaaS  B) PaaS  C) DaaS  D) **BaaS-as-hardware**

**2.** AWS S3 is an example of:
A) Block storage  B) **Object storage**  C) File storage  D) Database

**3.** Which scales automatically to zero when idle?
A) EC2  B) **Lambda**  C) RDS  D) EBS

**4.** The smallest deployable unit in Kubernetes is a:
A) Container  B) Node  C) **Pod**  D) Service

**5.** Which provides up to 90% discount but can be interrupted?
A) On-Demand  B) Reserved  C) **Spot**  D) Dedicated

**6.** Which tool is used for Infrastructure as Code?
A) Docker  B) **Terraform**  C) Grafana  D) Kafka

**7.** GDPR is a compliance standard for:
A) Payments  B) Healthcare  C) **EU data privacy**  D) US government

**8.** Which is a NoSQL database?
A) MySQL  B) PostgreSQL  C) **DynamoDB**  D) Oracle

**9.** A CDN primarily improves:
A) Security  B) **Latency**  C) Storage cost  D) Encryption

**10.** Which deployment model combines public and private cloud?
A) Multi-cloud  B) **Hybrid**  C) Community  D) Public

**11.** In the shared responsibility model, the provider is responsible for:
A) Your data  B) **Physical hardware**  C) IAM policies  D) App code

**12.** Prometheus is primarily used for:
A) CI/CD  B) **Metrics/monitoring**  C) IaC  D) Container runtime

**13.** Which is stateful in Kubernetes?
A) Deployment  B) **StatefulSet**  C) ReplicaSet  D) Service

**14.** RTO stands for:
A) Rapid Time Output  B) **Recovery Time Objective**  C) Real Time Ops  D) Resource Time Order

**15.** Which is an event streaming platform?
A) Redis  B) **Kafka**  C) Nginx  D) Terraform

## ✍️ Fill in the Blank

26. The five cloud characteristics include on-demand self-service, broad network access, resource pooling, rapid elasticity, and __________. *(measured service)*
27. __________ is the most popular container orchestration tool. *(Kubernetes)*
28. The principle of __________ means granting only necessary permissions. *(least privilege)*
29. __________ instances offer the deepest discount for interruptible workloads. *(Spot)*
30. A __________ distributes incoming traffic across multiple servers. *(load balancer)*
31. __________ encryption protects data moving over the network. *(In-transit / TLS)*
32. In CAP theorem, CAP stands for Consistency, Availability, and __________ tolerance. *(Partition)*
33. __________ is HashiCorp's tool for managing secrets. *(Vault)*
34. A __________ deployment gradually shifts traffic to a new version. *(Canary)*
35. __________ storage archives cold data cheaply on AWS. *(Glacier)*

---

## 💬 Short Answer

36. Name three benefits of cloud computing. *(cost efficiency, scalability, global reach, reliability, speed — any 3)*
37. Difference between horizontal and vertical scaling? *(more machines vs bigger machine)*
38. What does a Kubernetes Service provide? *(stable network endpoint for pods)*
39. Name two IaC tools. *(Terraform, CloudFormation, Pulumi, Ansible, Bicep)*
40. What is a cold start? *(latency when a serverless function starts from idle)*
41. Give two ways to reduce cloud costs. *(right-sizing, reserved/spot, auto-scaling, tiering, deleting idle)*
42. What is the difference between authentication and authorization? *(who you are vs what you can do)*
43. Name the three types of cloud storage. *(object, block, file)*
44. What is GitOps? *(Git as source of truth for deployments, auto-synced)*
45. What are the Four Golden Signals of monitoring? *(latency, traffic, errors, saturation)*
