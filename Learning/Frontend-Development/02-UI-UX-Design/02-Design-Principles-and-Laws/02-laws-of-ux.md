# ⚖️ Laws of UX

> 💼 **Industry Perspective:** In professional frontend teams, **Laws of UX** is applied to build reliable, scalable, and maintainable production software. Engineers are expected to understand its trade-offs, best practices, and how it fits into modern architecture, code reviews, and day-to-day team workflows.

> A set of research-backed principles (many named after psychologists) that predict how users perceive and interact with interfaces.

## 🧠 The One Big Idea

These "laws" are heuristics distilled from psychology and HCI research. Knowing them helps you design interfaces that *feel* effortless.

---

## 📚 Key Laws

| Law | What it says | Design implication |
|-----|-------------|--------------------|
| **Hick's Law** | More choices = longer decisions | Reduce/segment options |
| **Fitts's Law** | Time to target depends on size + distance | Big, close, easy-to-hit targets |
| **Jakob's Law** | Users expect your site to work like others | Follow conventions |
| **Miller's Law** | ~7±2 items in working memory | Chunk information |
| **Law of Proximity** | Nearby items are grouped | Spacing communicates grouping |
| **Postel's Law** | Be liberal in input, strict in output | Forgiving forms |
| **Peak-End Rule** | Users judge by peak + end moments | Polish key + final moments |
| **Doherty Threshold** | Keep responses <400ms | Fast feedback, loaders |

---

## 🎯 Applying Them

- **Fitts's Law** → make primary buttons large; put them within thumb reach on mobile.
- **Hick's Law** → progressive disclosure; hide advanced options.
- **Jakob's Law** → put the logo top-left, cart top-right — don't reinvent.
- **Doherty Threshold** → show skeletons/spinners for slow actions.

---

## 🎯 Key Takeaways

1. UX laws are **research-based heuristics**.
2. **Hick's** and **Fitts's** laws directly shape controls.
3. **Jakob's Law** — conventions reduce learning cost.
4. **Miller's Law** — chunk content into digestible groups.
5. Optimize the **peak and end** of experiences.
