# 🗂️ Information Architecture & Navigation

> 💼 **Industry Perspective:** In professional frontend teams, **Information Architecture & Navigation** is applied to build reliable, scalable, and maintainable production software. Engineers are expected to understand its trade-offs, best practices, and how it fits into modern architecture, code reviews, and day-to-day team workflows.

> **Information Architecture (IA)** is the structure and organization of content so users can find what they need and understand where they are.

---

## 🧠 The One Big Idea

If users can't find it, it doesn't exist. IA organizes content into logical, navigable structures.

---

## 🧱 Building Blocks

- **Hierarchy** — parent/child relationships (sitemap).
- **Taxonomy** — how content is categorized/labeled.
- **Navigation** — global, local, breadcrumb, footer.
- **Labeling** — clear, user-language names.

---

## 🃏 Card Sorting

Have users group and label content to discover *their* mental model.

- **Open** — users create categories.
- **Closed** — users sort into your categories.

---

## 🧭 Navigation Patterns

| Pattern | Use |
|---------|-----|
| Top nav bar | Few top-level sections |
| Sidebar | Apps/dashboards with many sections |
| Tabs | Switching views in one context |
| Breadcrumbs | Deep hierarchies |
| Mega menu | Large catalogs |

---

## 🎯 Key Takeaways

1. **IA** = structure + organization of content.
2. Use **hierarchy, taxonomy, navigation, labeling**.
3. **Card sorting** reveals users' mental models.
4. Pick **navigation patterns** to match depth/breadth.
5. Findability drives usability.
